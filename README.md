# AI Placement Trainer 🚀

An AI-powered platform designed to help students prepare for placement interviews and improve their job readiness.

## ✨ Features
- Aptitude Practice
- Technical Interview Preparation
- Group Discussion Practice
- AI Interview Practice
- Multiple Engineering Departments
- Performance Tracking and Assessment

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Firebase

## 🌐 Live Demo
https://ai-placement-trainer.web.app

## 🎯 Objective
To help students improve their aptitude, technical knowledge, communication skills, and interview confidence through an interactive preparation platform.
